⚡ Zero Database

No MySQL required. Your content is stored in clean JSON files, making backups as easy as copy-pasting a folder.

🎨 Theme Engine

Switch between Grid, List, and Single Column layouts instantly. Customize fonts and colors with real-time previews.

🛠️ Pro Dashboard

A WordPress-inspired admin interface with a persistent top bar, fixed sidebar, and built-in help guide.

📝 Rich Text Editing

Write beautiful posts with the integrated Jodit editor. Full support for media uploads and featured images.

🔒 Secure by Design

Password hashing, CSRF protection, and strictly validated file uploads keep your blog safe from the start.

🚀 98+ PageSpeed

Built with vanilla PHP and optimized CSS. No heavy frameworks means near-instant load times for your readers.
